# Style Anchors

Frozen reference set for magic sprite art. Everything under `.art/` sits outside
`Client/Assets/`, so Unity never imports it and it costs nothing at build time.

Read `STYLE.md` for the rules the anchors embody, and `CONCEPT-BRIEF.md` for the
generation prompts.

## Why frozen

New sprites are generated by conditioning on existing sprites. If each new sprite
references the *most recent* art, style error compounds — generation N inherits
every drift from N-1. Anchors break that chain: every generation references this
fixed set, never the latest output.

**Do not regenerate, retouch, or replace files in
`.art/anchors/master-v2/`.** Changing an anchor re-bases the whole style. If an
anchor is genuinely wrong, that is a deliberate style change — decide it
explicitly, then re-derive the affected art.

The copies here are frozen snapshots. The live sprites of the same name under
`Client/Assets/Resources/Art/Sprites/` may be edited independently; the anchor copy is
the one that defines style.

## Master v2 — canonical

Selected on 2026-07-28. This is the only production anchor set. Removed legacy
sprites must not be restored or used as generation references; inspect live
assets only when historical subject identity is required.

| Role | Anchor |
|---|---|
| Master comparison key | `master-v2/MasterStyleKey.png` |
| Human character / cloth / skin | `master-v2/ApprenticeMage.png` |
| World Tree spirit / foliage | `master-v2/WorldTreeSpirit.png` |
| Water slime / layered translucent color | `master-v2/WaterSlime.png` |
| Rock golem / stone / moss | `master-v2/RockGolem.png` |
| Human building / stone / metal | `master-v2/HumanMagicTower.png` |
| Hellfire demon / dark shell / inner glow | `master-v2/HellfireDemon.png` |
| Magic effect / shard silhouette | `master-v2/ArcaneImpact.png` |
| Environment hero object / tree | `master-v2/WorldTree.png` |

Rules:

- Use `MasterStyleKey.png` plus the closest one or two material anchors.
- Never use B, C, or D style candidates in a production prompt.
- Never edit these files in place. Propose a new versioned master set instead.
- The transparent single-subject anchors have no baked contact shadow.

## Unresolved

- **Ground shadow.** `RockGolem` carries contact debris; most others float clean.
- **Human vs golem grey.** Both currently sample to roughly `#A0A0A0`. `STYLE.md`
  proposes warm tan + moss for golems, cool grey + steel blue + bronze for
  humans. Existing sprites need a pass to enforce it.
- **`Towerback` faction.** Human masonry or golem?

## Regenerating sheets

```bash
./.art/make-sheets.sh
```

Writes `.art/sheets/master-v2-anchors.png`, `.art/sheets/sprites.png`, and —
once `.art/concept/` has files — `.art/sheets/concept.png`. Run the sprite sheet
after adding art and eyeball it: a new sprite that jumps out of the grid is a
reject.

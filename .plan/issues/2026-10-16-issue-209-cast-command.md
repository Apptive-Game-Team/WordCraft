# 2026-10-16: Cast 명령과 액티브 능력

- Date: 2026-10-16
- GitHub Issue: #209
- Status: Implemented (draft PR, #213 위에 쌓음)

## Goal

`docs/TECH-TREE.md` 구현 순서 묶음 8. `CommandType.Cast = 15`와 액티브 열 개. HUD 버튼, AI(묶음 9), 뷰 효과는 범위 밖이다.

## 명령

- `EntityId` 시전자, `Arg` 진영 능력 표 index, `Target` 지점. 새 `Command` 필드 없음.
- 거부 순서: 소유·생존 → 그 행을 가진 몸 → 해금 연구 → `AbilityCooldown == 0`(전개는 전환 중이면 거부) → 사거리 안의 지점(간헐천은 물 지대 셀, 깨우기는 잔해 셀) → 자원(깨우기는 인구 상한도). 하나라도 걸리면 상태를 건드리지 않는다.
- 통과하면 비용 차감, 쿨다운 시작, 종류별 효과.

## 액티브와 종류

| 능력 | 보유 | 종류 | 처리 |
|---|---|---|---|
| 물 지대 깔기 | 물방울 생존자 | 즉발 | `Apply`가 자기 셀 3×3에 300틱(물 지대 지속 450) |
| 해일 부름 | 해일 인도자 | 즉발 | `Apply`가 지점 3×3 물 지대 300틱, `pendingBursts`에 고정 20 |
| 굳기 | 성벽 골렘 | 즉발 | `Apply`가 `Kill` 뒤 자기 셀과 상하좌우 4셀에 잔해 600틱(굳기 지속 900) |
| 깨우기 | 이끼 현자 | 즉발 | `Apply`가 잔해 소비, 셀 중심에 깨어난 바위(`SpawnUnit`). 자원 40(깨우기 비용 25) |
| 유성우 | 운석 술사 | 지연 | 40틱 뒤 `pendingBursts`, 고정 30 |
| 간헐천 | 간헐천 술사 | 지연 | 20틱 뒤 고정 25 |
| 낙뢰 | 마도사 | 지연 | 30틱 뒤 고정 22, 공중 제외 |
| 칼바람 회오리 | 바람 정령 | 지속 구역 | 60틱, 10틱마다 고정 3 |
| 모래폭풍 | 모래 술사 | 지속 구역 | 100틱, 안의 적 몸 사거리 최대 3, 속도 × 1/2 |
| 전개 | 견인 대포 | 전환 | 40틱 뒤 `Deployed` 뒤집기. 전개 중 사거리 10, 반경 1칸 광역, 이동 거부 |

## 시계

시전 틱 T에 `AbilityTicksLeft = N`. 그 틱의 `AbilitySystem`은 이 시계를 세지 않는다(시전 목록은 틱 안에서만 쓰는 임시 목록이라 해시하지 않음). 그래서 지연 폭발은 T+N에 터지고, 구역은 T부터 T+N-1까지 N틱 동안 `CombatSystem`·`MoveSystem`에 읽히고, 전개는 T+N에 뒤집힌다. 칼바람 회오리는 화상과 같은 규칙으로 줄인 뒤 값이 10의 배수인 틱(T+10 … T+60)에 6번 친다.

## 해시

새 필드 둘: `Entity.AbilityPoint`(X, Y raw), `Entity.Deployed`. `Kill`이 지운다.

## 정적 데이터

- `AbilityKind` 28~35, `AbilityRow`에 `CastRange`, `Cost`, `BoostedCost`.
- 연구 행 아홉: 칼바람 회오리, 유성우, 해일 부름, 물 지대 지속, 굳기 지속, 깨우기 비용, 모래폭풍 반경, 전개 장치, 낙뢰. 세계수 정령과 인간이 14행이 되어 `MaxUpgrades` 13 → 14.
- `ContentVersion` 38 → 39.

## 결과

- 골든 해시 `0x41023E12FEFCD38D` → `0x89303B33ED3EA28D`. CoreCLR과 Unity Mono가 같은 값을 냈다.
- 스크립트 로그의 `Cast`는 행 규칙에서 거부된다. 600틱 안에 액티브를 가진 세계수 정령·지옥불 몸을 해금까지 갖출 수 없다(바람 토템, 연구, 바람 정령이 빨라야 670틱 뒤). 수락되는 `Cast`는 `Host -- selfcheck` 손실 링크 매치(물 지대 깔기)가 덮는다.
- 문서에 없는 판단: 같은 셀 안의 걸음은 늘 받는다(굳기 잔해 위 몸이 나가도록), 모래폭풍 감속은 휘감기·덩굴 지대와 합쳐 한 번, 전개 `Cast`는 명령과 길을 지운다, 해일 부름은 `AbilityPoint`를 쓰지 않는다.
- `CastChecks` 검사 22개를 하나씩 일부러 깨서 모두 실패하는 것을 확인했다.

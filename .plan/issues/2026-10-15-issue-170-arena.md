# 2026-10-15 — Host arena 명령 추가

- Date: 2026-10-15
- GitHub Issue: #170
- Status: Complete

## Goal

Host에서 여섯 진영의 순서 있는 36쌍을 AI 대 AI로 실행하고, 매 틱 hash를 두 실행 사이에서 비교한 뒤 승률을 출력한다.

## Non-goals

- Sim, Replay, Client 변경과 밸런스 수치 조정.
- thread 병렬 실행과 시뮬레이션 성능 변경.

## Context / Constraints

- 각 판은 `MatchScenario.Build`로 만들고 두 피어에 `SetPeerAi`를 적용한다.
- 기본값은 쌍마다 한 판, 6000틱, seed `0xC0FFEE`이다. 같은 쌍의 판마다 seed에 game index를 더한다. 짝수 game index에서 진영 `a`는 peer 0이고, 홀수 game index에서 진영 `a`는 peer 1이다.
- `Sim/`은 현재 `World.Random`에서 난수를 뽑지 않는다. 따라서 `-seed`와 `seed + game index`는 hash RNG 상태만 바꾸며, 여러 판의 게임 결과를 바꾸는 요인은 진영의 peer 자리 교대뿐이다.
- 쓰기 범위는 issue #170의 여섯 파일과 이 plan 파일로 제한한다.

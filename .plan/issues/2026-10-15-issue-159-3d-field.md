## Context / Constraints

- 뷰는 시뮬레이션을 읽기만 한다.
- Unity 2022 LTS 내장 렌더 파이프라인. 메시와 머티리얼은 전부 런타임 생성.
  지금 뷰가 `RuntimeInitializeOnLoadMethod` 로 씬을 코드에서 세우는 구조를
  그대로 따른다.
- 셰이더는 `Client/Assets/Resources/Shaders/` 에 두고 `Resources.Load<Shader>`
  로 집는다. Resources 밖의 셰이더는 아무 머티리얼도 참조하지 않으면 빌드에
  들어가지 않는다.
- `.art/STYLE.md` 의 렌더링 규칙이 그대로 적용된다. 값 세 단계, 외곽선 없음,
  좌상단 단일 광원, 채도 절제. 그 규칙을 조명 함수로 옮긴 것이
  `Resources/Shaders/Paper.cginc` 다.
- `docs/UI-STYLE.md` 의 색 토큰이 정본이다. 필드 색은 `UiStyle` 에서 읽는다.

## 좌표 계약

시뮬레이션은 2차원이고 축이 x, y 다. 뷰는 그것을 눕힌다.

```text
sim (x, y)  ->  world (x, Field.Height(x, y), y)
```

sim x = world x, sim y = world z, world y = 높이. 변환은 `Field.At` 과
`Field.Plane` 둘뿐이고, 다른 어디서도 sim 좌표로 Vector3 를 조립하지 않는다.
`MatchRunner.ToView`/`ToSim` 은 그대로 둔다 — 그 둘은 평면 좌표를 다루고,
`ViewSelfCheck.ConversionRoundTripsExactly` 가 고정점 왕복을 그 위에서 검사한다.

`Client/Assets/Scripts/Field.cs` 가 이 계약의 구현이고 이미 들어가 있다. 요약:

```csharp
const float LevelHeight = 0.85f;   // 한 레벨의 월드 단위 높이
const float WaterDrop   = 0.30f;   // 물 표면이 셀 레벨보다 내려간 깊이
const float WaterDepth  = 0.45f;   // 그 표면 밑의 바닥
const float RockLift    = 0.55f;   // 암반 셀의 들린 높이
const int   Cells       = 64;

static void  Build(World world);              // 맵 한 번
static bool  Ready { get; }
static float Height(float x, float z);        // 월드 단위 지면 높이
static float Height(Vector2 plane);
static Vector3 At(Vector2 plane);             // 지면에 놓인 점
static Vector3 At(Vector2 plane, float lift); // 지면에서 띄운 점
static Vector2 Plane(Vector3 world);
static Vector3 Normal(float x, float z);
static float Corner(int cell, int corner);    // 셀당 4개. 0:-x-z 1:+x-z 2:-x+z 3:+x+z
static float Flat(int cell);                  // 물·암반의 평평한 윗면
static float Bed(int cell);                   // 호수 바닥
static int   Level(int cell);
static TileKind Kind(int cell);
static bool  Cliff(int a, int b);             // 두 셀 사이가 절벽인가
static bool  Pointer(Camera cam, Vector2 screen, out Vector2 plane);
```

코너 높이 규칙이 지형의 모양을 정한다. 코너는 자기를 포함해 최대 네 셀이
만나는 자리이고, **자기와 한 레벨 이내인 셀만** 평균한다. 그래서 1레벨 차이는
걸어 올라가는 경사가 되고, 2레벨 이상 차이는 양쪽 셀이 각자 자기 레벨에서
평평하게 끝나 그 사이가 수직으로 벌어진다. 그 벌어진 틈이 절벽면이고 FieldMesh
가 메운다. 물과 암반은 평균에 끼지 않는다.

## 셰이딩 계약

`Resources/Shaders/Paper.cginc` 가 조명 모델이다. 이것을 include 하는 셰이더는
전부:

- Input 구조체에 `float3 worldPos;` 를 둔다.
- `#pragma surface surf WcPaper ... nofog finalcolor:<자기 함수>` 로 쓴다.
- finalcolor 함수에서 `WcAtmosphere(IN.worldPos, colour)` 를 부른다. 전장의
  안개와 거리 헤이즈가 거기서 들어간다.

전역 값(`_WcFog`, `_WcFogParams`, `_WcFogTint`, `_WcSkyLight`, `_WcEarthLight`,
`_WcBands`, `_WcRim`, `_WcHaze`, `_WcHazeRange`, #187 부터 `_WcField`)은 뷰가 프레임마다 한 번
`Shader.SetGlobal*` 로 넣는다. 머티리얼마다 복사본을 갖지 않는다.

## 모델 계약

```csharp
// Client/Assets/Scripts/Models.cs
public static class Models
{
    // 로스터 한 항목의 바디를 만들어 parent 아래에 붙인다. local position 0.
    public static BodyRig Build(Transform parent, Faction faction, Role role, int slot,
                                EntityKind kind, int owner, bool neutral);
}

// Client/Assets/Scripts/BodyRig.cs
public sealed class BodyRig : MonoBehaviour
{
    public float Footprint { get; }  // 셀 단위. 링이 비켜야 하는 지름
    public float Top { get; }        // 체력바가 뜨는 높이(월드 단위, 지면 기준)
    public void Place(Vector3 ground);   // 위치. 이동 방향에서 바라보는 방향과 걸음을 끌어낸다
    public void Face(float yawDegrees);
    public void Attack();                // 한 번의 공격 동작
    public void Hit();                   // 피격 반응
    public void Progress(float t);        // 0..1 건설 진행
    public void Tint(Color multiply);
    public void Alpha(float a);
    public void Show(bool on);
    public void Dim(bool remembered);     // 안개 속 기억된 건물
}
```

## Risks & Rollback

- **Risks:** 컴파일은 Unity 에서만 확인된다. perspective 전환으로 화면 좌표를
  읽던 모든 자리(선택, 명령, 미니맵, 오프스크린 표시)가 영향을 받고, 하나를
  놓치면 클릭이 엉뚱한 곳으로 떨어진다. 그림자와 MSAA 는 품질 설정에 걸려
  있어 런타임에서 명시적으로 켜야 한다.
- **Rollback steps:** `git revert`. 뷰 전체가 한 브랜치에 있으므로 되돌리면
  스프라이트 뷰로 돌아간다.

# 진영 로스터

WordCraft의 5진영, 유닛, 건물 정본 문서다. 세계관 사실은
WordOnline `client/.art/WORLD.md`가 정본이고 이 문서는 그것을 RTS 구조로
번역한다. 원문에 없는 설정을 확정 사실처럼 추가하지 않는다.

## 아트 규칙

`client/.art/STYLE.md`의 두 축을 그대로 따른다.

- **렌더링 기법은 전 진영 동일하다.** 2.5D cut-paper, 2026-07-28 동결.
  이것이 게임을 하나의 게임으로 읽히게 한다.
- **형태 언어와 팔레트는 진영마다 다르다.** 이것이 진영을 한눈에 구분되게 한다.

두 축을 섞는 것이 과거 실패 원인이다. "지옥불은 무섭게 보여야지"가 "다른 모델로
생성"으로 번져 기법이 깨졌다. 새 아트는 `client/.art/anchors/master-v2/`를
참조하고, 최신 출력물을 참조하지 않는다. 최신 것을 참조하면 세대마다 드리프트가
누적된다.

숫자 접미사는 별개 캐릭터가 아니라 상태 프레임이다. `RockGolem2`는 골렘 2호가
아니라 공격 자세다.

## 공통 구조

모든 진영이 같은 역할 구조를 가진다. 이름과 외형만 다르다.

| 역할 | 설명 |
|---|---|
| 본진 | 자원 하역 지점. 파괴되면 패배 조건에 관여한다. |
| 일꾼 | 자원 노드에서 채집해 본진으로 나른다. 전투 능력 없음. |
| 생산 건물 | 전투 유닛을 큐에 넣어 생산한다. |
| 방어 건물 | 고정 포탑. 이동 불가. |
| 근접 유닛 | 사거리 짧고 체력 높음. |
| 원거리 유닛 | 사거리 길고 체력 낮음. |
| 진영 유닛 | 진영 정체성을 드러내는 세 번째 유닛. |

승리 조건: 상대 본진 파괴. 시뮬레이션 안에서 판정한다.

## 1. 세계수 정령

워드가 죽은 자리에 자란 세계수에서 태어난 전기·풀·바람 정령. 슬라임과는 다른
종족이다. 아트 자산이 가장 많은 진영이다.

| 역할 | 이름 | 스프라이트 | 상태 |
|---|---|---|---|
| 본진 | 생명의 나무 | `LifeTree` | 있음 |
| 일꾼 | 풀씨 정령 | `SeedSpiritSwarm` | 있음 |
| 생산 건물 | 풀씨 둥지 | `SeedNest` | 있음 |
| 방어 건물 | 전기 타워 | 신규 필요 | `ElectricTower`는 인간 문명 제작물이라 쓸 수 없음 |
| 근접 | 고목 수호자 | `TreeGolem` / `TreeGolem2` | 있음, 기본·공격 2프레임 |
| 원거리 | 번개 정령 | `ThunderSpirit` | 있음 |
| 진영 | 바람 정령 | `WindSpirit` | 있음 |

여유 자산: `VineSpirit`, `VineColony`, `GiantVine`, `Overgrowth`, `Leafair`,
`ThunderBirdSwarm`, `ZapMouse`, `RazorGale`, `StormRider`, `WillOWisp`,
`WindTotem`, `HealingTotem`, `FrenzyTotem`.

### 신규 컨셉 — 정령 뇌우목 (방어 건물)

- 형태: 뒤틀린 채 위로 뻗은 마른 가지 다발. 상단에서 가지 끝이 서로 마주 보며
  아크를 만든다. 인간이 만든 금속 타워와 달리 조립된 부품이 없다.
- 팔레트: 젖은 목재 갈색과 이끼 초록, 아크 부분만 창백한 청백색.
- 금지: 스틸블루 금속, 볼트, 받침대, 회색 석재. 그건 인간 문명의 언어다.

## 2. 지옥불 군단

지옥불 차원에서 넘어온 침략 세력. 불의 정령이 아니라 악마에 가까운 존재다.
유닛 자산은 충분하지만 **건물 자산이 하나도 없다.**

| 역할 | 이름 | 스프라이트 | 상태 |
|---|---|---|---|
| 본진 | 균열 제단 | 신규 필요 | |
| 일꾼 | 잿불 악마 | `EmberSpiritSwarm` | 있음 |
| 생산 건물 | 악마 산란장 | 신규 필요 | |
| 방어 건물 | 용암 아가리 | 신규 필요 | |
| 근접 | 용암 갑각 악마 | `MagmaSpirit` 3상태 | 있음, 소환·기본·공격 |
| 원거리 | 지옥불 군단장의 자손 | `FireChildSpirit` | 있음 |
| 진영 | 지옥불 군단장 | `FireLordSpirit` | 있음, 공중 |

여유 자산: `FireSpirit`, `Crater`, `CraterEmber`, `MagmaExplosion`.

### 신규 컨셉 — 균열 제단 (본진)

- 형태: 지면을 가르고 솟은 검붉은 갑각판이 아치를 이루고, 그 안쪽이 다른 차원을
  향해 열려 있다. 건축물이라기보다 상처에 가깝다.
- 팔레트: 검붉은 갑각, 갈라진 틈의 내부 용암광, 열린 면만 창백한 주황.
- 금지: 문, 창문, 계단, 깃발. 악마는 짓지 않고 뚫고 나온다.

### 신규 컨셉 — 악마 산란장 (생산 건물)

- 형태: 낮고 넓은 갑각 주머니. 표면에 맥동하는 융기가 있고 아래쪽이 갈라져 있다.
- 팔레트: 균열 제단과 동일 계열, 융기부만 더 밝은 잿불색.
- 참고: `client/.art/MAGIC-CATALOG.md`가 고아 상태인 원소 둥지 6종의 처리
  방안으로 "지옥불 군단의 악마 산란장으로 교체"를 이미 제시하고 있다. 이 컨셉이
  그 제안을 그대로 구현한다.

### 신규 컨셉 — 용암 아가리 (방어 건물)

- 형태: 지면에 반쯤 묻힌 갑각 턱. 발사 시에만 벌어진다.
- 팔레트: 검붉은 갑각, 내부 용암광.
- 금지: 포신, 총구, 기계 조준부.

## 3. 물 슬라임

과거부터 존재한 온건파 종족. 온건했기 때문에 살아남았고 동족은 모두 죽었다.
세계수 정령과 구분해야 한다.

| 역할 | 이름 | 스프라이트 | 상태 |
|---|---|---|---|
| 본진 | 수맥 웅덩이 | 신규 필요 | |
| 일꾼 | 물방울 생존자 | `WaterSlimeSwarm` | 있음 |
| 생산 건물 | 거품 생성기 | `BubbleGenerator` | 있음. 세계관상 인간 장치이므로 재귀속 판단 필요 |
| 방어 건물 | 물기둥 분수 | 신규 필요 | |
| 근접 | 거품 정령 | `BubbleSpirit` | 있음 |
| 원거리 | 물결 궁수 | `AquaArcher` / `AquaArcherAttack` | 있음, 당긴·놓은 2프레임 |
| 진영 | 구름 용 | `CloudDragon` | 있음, 공중 |

여유 자산: `WaterSlimeAttackSpit`, `RainCloud`, `TideCall`, `WaterExplosion`,
`WaterField`.

### 신규 컨셉 — 수맥 웅덩이 (본진)

- 형태: 반투명 물질 종이층이 겹쳐 만든 얕은 분지. 가장자리가 둥글고 낮다.
  위협적인 각도가 없다.
- 팔레트: 반투명 청록, 바닥으로 갈수록 짙어짐.
- 금지: 성벽, 방벽, 뾰족한 실루엣. 온건파 종족이다.

### 신규 컨셉 — 물기둥 분수 (방어 건물)

- 형태: 낮은 물 고리에서 솟는 물기둥. 발사 시 기둥이 기울어 표적을 향한다.
- 팔레트: 수맥 웅덩이와 동일.
- 금지: 노즐, 파이프, 기계 부품.

## 4. 돌 골렘 부족

정령과 별개의 부족. 인간이 만든 회색 기계가 아니라 따뜻한 바위와 이끼로 이루어진
독립 부족이다. 카탈로그가 `RockTurret`을 "인간제 석조 포탑, 골렘 계열과 분리
필요"로 명시하고 있으므로 이 진영 자산으로 쓰지 않는다.

| 역할 | 이름 | 스프라이트 | 상태 |
|---|---|---|---|
| 본진 | 이끼바위 성소 | 신규 필요 | |
| 일꾼 | 꼬마돌 | `MiniRockSwarm` | 있음 |
| 생산 건물 | 각성 바위 | 신규 필요 | |
| 방어 건물 | 굴림바위 언덕 | 신규 필요 | |
| 근접 | 이끼바위 골렘 | `RockGolem` / `RockGolem2` | 있음, 기본·공격 2프레임 |
| 원거리 | 바위 술사 | `RockMage` | 있음 |
| 진영 | 바위 잔해 | `RockRemnant` | 있음. 골렘 사망 시 남는 상태로 이미 정의됨 |

여유 자산: `RockRolling`, `RockDrop`, `SandStorm`, `Crater`.

`RockRemnant`는 독립 유닛이 아니라 골렘 사망 후 20초간 지상 이동을 막는 생애주기
상태다. 이 진영의 정체성이므로 유닛 슬롯이 아니라 골렘의 사망 규칙으로 구현한다.
진영 유닛 슬롯은 비워 두고 아트가 생기면 채운다.

### 신규 컨셉 — 이끼바위 성소 (본진)

- 형태: 이끼 덮인 큰 바위 세 개가 서로 기대 만든 낮은 아치. 다듬은 흔적이 없다.
- 팔레트: 따뜻한 탄색 석재, 이끼 초록.
- 금지: 차가운 스틸블루, 기계 결합부, 직각 절단면.

### 신규 컨셉 — 각성 바위 (생산 건물)

- 형태: 표면에 이끼 균열이 번진 둥근 바위. 균열 사이로 따뜻한 빛이 보인다.
  생산은 조립이 아니라 깨어남이다.
- 팔레트: 성소와 동일.

### 신규 컨셉 — 굴림바위 언덕 (방어 건물)

- 형태: 낮은 흙 둔덕 위에 얹힌 둥근 바위. 공격은 발사가 아니라 굴러 내려가는 것.
- 팔레트: 성소와 동일.
- 금지: 포신, 조준부, 발사구.

## 5. 차원 유랑종

여섯 다리 껍질 안에 다른 세계를 품고 이동하는 세계 파편. 셋은 부모·자식 관계가
아니라 서로 다른 독립 종이다. **아트가 3종뿐이라 로스터가 가장 얇다.**

| 역할 | 이름 | 스프라이트 | 상태 |
|---|---|---|---|
| 본진 | 정박한 세계 | 신규 필요 | |
| 일꾼 | 화산편 | `FireTadpole` | 있음 |
| 생산 건물 | 통로 | 신규 필요 | |
| 방어 건물 | 굴절 기둥 | 신규 필요 | |
| 근접 | 폭풍편 | `LightningTadpole` | 있음 |
| 원거리 | — | 신규 필요 | 아트·컨셉 모두 없음 |
| 진영 | 경계 운반자 | `DimensionToad` | 있음. 직접 공격하지 않고 도주한다 |

`DimensionToad`는 원문에서 직접 공격하지 않는 개체다. 전투 유닛으로 바꾸지 않고,
10초마다 통로를 여는 원래 능력을 RTS 규칙으로 옮긴다. 주기적으로 자기 위치에
화산편 또는 폭풍편을 번갈아 소환한다.

다른 진영에서 유닛을 빌려오지 않는다. 진영 정체성이 무너진다. 빈 슬롯은 스탯만
정의하고 아트가 생길 때까지 도형으로 렌더링한다.

### 신규 컨셉 — 정박한 세계 (본진)

- 형태: 지면에 반쯤 박힌 거대한 아치형 껍질. 무광 외피판 사이로 실제 공간 깊이를
  가진 축소 외부 세계가 보인다.
- 팔레트: 무광 회갈색 외피, 틈새 안쪽만 다른 세계의 색.
- 금지: 보석, 알, 화면, 기계, 두꺼비 해부 구조. 매니페스트가 명시한 금지 사항이다.

### 신규 컨셉 — 통로 (생산 건물)

- 형태: 두 외피판이 벌어져 만든 세로 균열. 안쪽이 다른 세계로 이어진다.
  유닛은 만들어지는 것이 아니라 건너온다.
- 팔레트: 정박한 세계와 동일.

### 신규 컨셉 — 굴절 기둥 (방어 건물)

- 형태: 외피판 조각이 공중에 정지한 채 회전한다. 지지대가 없다.
- 팔레트: 무광 외피, 회전면에만 다른 세계의 빛.
- 금지: 받침대, 기초, 케이블.

## 인간 마법 문명에 대하여

`client/.art/WORLD.md`에는 여섯 번째 세력인 인간 마법 문명이 있고, RTS에 가장
어울리는 건물 아트를 이미 갖고 있다. `Cannon`, `Tower`, `ElectricTower`,
`RockTurret`, `ManaWell`, `BubbleGenerator`, 그리고 `ChickenCommando`,
`Towerback`.

WordCraft는 5진영으로 결정했으므로 이 자산은 이번 범위에 넣지 않는다. 다만 다섯
진영의 건물 컨셉을 새로 쓰는 이유가 이것이다. 기존 건물 아트는 대부분 인간
문명 소유이고, 그것을 다른 진영에 붙이면 진영 구분이 무너진다.

여섯 번째 진영으로 추가할지는 열린 결정으로 남긴다. 추가한다면 건물 아트가 이미
있는 유일한 진영이 된다.

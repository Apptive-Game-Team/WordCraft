# 도감과 전장 모델의 대응

형태의 기준은 [Arcane Casters 공식 도감](https://theevilent.com/arcane-casters/magic)이다. 2026-10-16 브라우저에서 도감 이미지를 확인했다. 로컬 HUD PNG보다 사이트의 현재 형태를 우선한다. 전장 모델은 `Models.cs`와 `Models.Catalog*.cs`의 절차적 3D 메시이며, HUD 이미지만 교체해서는 전장 외형이 바뀌지 않는다.

## 이번 교정

| 도감 캐릭터 | 전장에 반영한 식별 특징 |
|---|---|
| Leafair | 얼굴과 별도 칼을 제거한 긴 겹잎 다발 |
| VineSpirit | 넓은 잎 얼굴틀과 연속된 S자 덩굴 |
| SeedSpiritSwarm | 큰 두 잎과 꽃, 손도구 제거 |
| ThunderSpirit | 손에 쥔 무기 대신 몸에 붙은 번개 갈기 |
| WindSpirit | 뒤로 흐르는 잎 실루엣 |
| TreeGolem | 원통형 나무 머리와 새싹 가지 |
| WaterSlimeSwarm | 둥근 젤 몸통과 발밑 거품, 큰 눈 |
| BubbleSpirit | 둥근 몸과 감긴 물꼬리 |
| AquaArcher | 청록 몸체와 곡선 활·시위·화살 |
| CloudDragon | 구름 덩어리, 작은 청록 날개, 노란 등가시와 코 |

세계수의 일부 다른 모델에서는 원형을 가리던 굵은 팀색 띠도 줄였다. 팀 구분 표식과 선택 표시, 기존 보행·부유·공격 리그는 유지한다.

## 해석의 경계

- 도감은 캐릭터의 생김새와 정체성을 정한다. 기존 master-v2 재질·조명·종이 조형 스타일을 새 스타일로 교체하지 않는다.
- RTS 역할·종족 배치·유닛 수치는 별도의 게임 설계다. 예를 들어 운룡의 현재 물 진영 배치는 이번 외형 교정에서 변경하지 않는다.
- 도감에 없는 RTS 확장 유닛과 건물을 원작 캐릭터라고 표기하지 않는다. 모든 모델을 도감과 일치시켰다는 의미도 아니다.
- 원본 PNG와 고정된 스타일 앵커는 덮어쓰지 않는다.

## 확인 자료

`Client/Logs/art-canon-before/`와 `Client/Logs/art-canon-after/`에 같은 조건의 종족 라인업과 대기·이동·공격 스트립을 저장한다. 이 이미지들은 렌더 및 리그 검증용이며 실제 조작 플레이 검증을 대신하지 않는다.

2026-10-16 검증: 수정 후 72장 생성 성공(라인업 18장, 동작 스트립 54장). 수정한 4종족 라인업과 대표 이동·공격 스트립을 육안 비교했다. 새 부품 분리나 비정상 뒤틀림은 관찰하지 못했다. 기존 라인업 촬영 구도에서는 마지막 대형 유닛이 오른쪽 가장자리에 일부 잘리므로 전체 형태는 별도 동작 스트립도 함께 본다. Unity `ViewSelfCheck.Run` 통과, 600틱 최종 해시 `D7F7252F1ECBEC6D` 유지.
